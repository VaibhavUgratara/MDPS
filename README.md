# 🩺 MediPredict — Multiple Disease Prediction System

MediPredict is a **machine learning-powered healthcare web application** built with **Python and Streamlit**. It provides an interactive interface for performing predictions for multiple diseases using pre-trained machine learning models.

The application also includes a user authentication system with **SQLite-based user storage** and **OTP-based registration using Twilio SMS**, providing an additional layer of account verification.

> **Disclaimer:** This project is intended for educational and demonstration purposes only. The predictions generated by the application should not be considered medical advice, diagnosis, or a substitute for consultation with a qualified healthcare professional.

---

## ✨ Features

### 🔐 User Authentication

MediPredict includes a basic authentication system that allows users to create and access accounts.

* User registration
* User login
* Username and password authentication
* Password hashing using SHA-256
* SQLite database for storing user credentials
* Phone-number-based OTP verification during registration
* Session-based login state using Streamlit Session State

The application uses Twilio to send OTP messages during registration.

---

## 🧪 Prediction Modules

### 1. Diabetes Prediction

The diabetes module accepts clinical features such as:

* Number of pregnancies
* Glucose level
* Blood pressure
* Skin thickness
* Insulin
* BMI
* Diabetes Pedigree Function
* Age

The collected values are converted to numerical values and passed to the trained diabetes classification model.

---

### 2. Heart Disease Prediction

The heart disease module uses parameters including:

* Age
* Sex
* Chest pain type
* Resting blood pressure
* Serum cholesterol
* Fasting blood sugar
* Resting ECG results
* Maximum heart rate
* Exercise-induced angina
* ST depression
* Slope
* Major vessels
* Thalassemia-related feature

The input values are passed to the trained heart disease model to generate a prediction.

---

### 3. Parkinson's Disease Prediction

The Parkinson's module uses voice-related biomedical features such as:

* MDVP fundamental frequency values
* Jitter measurements
* Shimmer measurements
* Noise-to-harmonics ratio
* Harmonics-to-noise ratio
* RPDE
* DFA
* Spread measurements
* D2
* PPE

The application collects the feature values through the Streamlit interface and passes them to the Parkinson's prediction model.

---

### 4. Breast Cancer Prediction

The breast cancer module uses numerical tumor-related features including:

* Radius
* Texture
* Perimeter
* Area
* Smoothness
* Compactness
* Concavity
* Concave points
* Symmetry
* Fractal dimension
* Standard-error features
* Worst-case features

The trained model classifies the input into the corresponding prediction category.

---

### 5. Anemia Prediction

The anemia module accepts:

* Gender
* Hemoglobin
* MCH

* MCV

The values are processed and passed to the trained anemia classification model.

### 6. Kidney Disease Prediction

The kidney disease module collects multiple clinical parameters including:

* Red blood cell information

The collected information is passed to the kidney disease prediction model.

# 🔑 Environment Variables

The application uses `python-dotenv` to load environment variables and reads Twilio credentials for OTP delivery.

Create a `.env` file in the project root:

```env
TWILIO_ACCOUNT_SID=your_twilio_account_sid
TWILIO_AUTH_TOKEN=your_twilio_auth_token
TWILIO_PHONE_NUMBER=your_twilio_phone_number
```

### Important

Never commit real API credentials to GitHub.

If credentials have previously been committed to a public repository, rotate/revoke them from the corresponding service before continuing.

# 📱 OTP Registration Flow

The registration process works approximately as follows:

```text
User enters
Username + Phone + Password
             │
             ▼
       Generate OTP
             │
             ▼
       Twilio SMS
             │
             ▼
       User enters OTP
             │
             ▼
       Verify OTP
             │
             ▼
       Create SQLite User
             │
             ▼
          Login
```

The application generates a four-digit OTP and attempts to send it through Twilio. After successful verification, the user's credentials are added to the SQLite database.

# ⚠️ Error Handling

The application includes input validation for the prediction forms.

If a user enters a value that cannot be converted into a numerical value where numerical input is expected, the application displays an invalid-entry notification instead of directly passing the invalid data to the model.

# 🔒 Security Considerations

This project demonstrates authentication and OTP concepts, but it should **not be considered production-ready healthcare software** without additional security work.

For a production deployment, consider implementing:

* Strong password hashing such as Argon2 or bcrypt
* Secure session management
* OTP expiration
* OTP attempt limits
* Rate limiting
* HTTPS
* Secure cookie configuration
* Encrypted sensitive information
* Proper secrets management
* Database access controls
* Audit logging
* Input sanitization
* CSRF protection where applicable
* Removal of sensitive files from version control

In particular, avoid committing `.env`, `users.db`, or temporary OTP data to a public repository.
